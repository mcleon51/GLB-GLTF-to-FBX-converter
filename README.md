# GLB / GLTF → FBX converter

Небольшое Windows-приложение с GUI для пакетной конвертации 3D-моделей в FBX.
Работает через установленный Blender в headless-режиме (`blender -b`), поэтому
не требует ни внешних SDK, ни внешних конвертеров.

## Возможности

- Drag & drop файлов прямо в окно (либо добавление через кнопку).
- Пакетная конвертация — можно закинуть сразу десятки файлов.
- Автопоиск `blender.exe` в стандартных путях установки и в реестре.
- Результат сохраняется **в папку исходного файла**, рядом с оригиналом.
- Журнал выполнения и цветовая пометка статуса каждого файла.
- Поддерживаются входные форматы: `.glb`, `.gltf`, `.obj`, `.fbx`, `.blend`.

## Требования

- Windows
- [Python 3.10+](https://www.python.org/downloads/) (tkinter входит в стандартную поставку)
- [Blender](https://www.blender.org/download/) 3.x или новее

## Запуск

Проще всего — двойным кликом по `launcher.bat`. Скрипт сам поставит
`tkinterdnd2` и запустит приложение.

Вручную:

```bash
pip install -r requirements.txt
python converter.py
```

Укажите путь к `blender.exe` в поле «Blender» или нажмите кнопку «Найти»
(путь сохраняется в `settings.json`, который не отслеживается git).

## Как это работает

`converter.py` — GUI-оболочка. Для каждого файла она запускает отдельный
процесс:

```bash
blender.exe -b --python blender_convert.py -- <input> <output>
```

`blender_convert.py` выполняется внутри Blender: очищает сцену, импортирует
исходник, экспортирует FBX и печатает в stdout маркер результата —
`OK:`, `ERROR:` или `MISSING:`. По нему GUI определяет успех.

Коды возврата `blender_convert.py`:

| Код | Значение                  |
|-----|---------------------------|
| 0   | успех                     |
| 2   | не переданы аргументы     |
| 3   | входной файл не найден    |
| 4   | ошибка конвертации        |
| 5   | результат не создан       |

## Структура

```
converter.py        GUI, настройки, автопоиск Blender
blender_convert.py  скрипт конвертации, выполняется внутри Blender
launcher.bat        установка зависимостей и запуск
requirements.txt    зависимости
```
